# UniKostyl

Расширенная версия проекта [OpenKostyl](https://github.com/WildBoar228/OpenKostyl).
Предоставляет интерфейс для цветовой калибровки камеры, т.е. подбора цветового диапазона в формате LAB для некоторых объектов интереса.

### Для запуска :

- открыть файл `cv_kostyl.py`: принимает в качестве аргумента кадр с камеры, обеспечивает работу
  с пользовательским интерфейсом.
  `работа приложения`
  Вводиться IP адрес одноплатника => Выделение и калибровка цветового диапозона => Отправка цветового диапазона (кнопка `save`) в формате RGB обратно на одноплатник

## Управляющие файлы

- `cv_kostyl.py`: использует веб-камеру устройства.
- `unikostyl.py`: UI и логика трекинга. Первые 3 слота порогов (Gate 1..3)
  отслеживаются одновременно, каждый со своим углом от центра кадра.
  На маске они красятся в свой цвет (жёлтый/синий/оранжевый).
  Вокруг центра нарисована фиксированная круговая зона (радиус = 25% от min(w,h)) —
  если выбранная кнопкой `TARGET G*` цель попадает в зону, считается угол и
  примерная дистанция до предмета по формуле `Z = W_cm * (w/π) / w_px` (равноугольная
  fisheye-проекция). Целевой предмет — мяч диаметром 42 мм (`KNOWN_TARGET_WIDTH_CM = 4.2`).
  Настройте константу под реальный предмет; в режиме `FISHEYE: RING` дистанция не считается (н/д). Углы печатаются в
  консоль раз в секунду и в панели логов; на видео кадров подписи не рисуются.
- `rpi_elp_cam.py`: главный файл на Raspberry Pi для USB-камеры ELP (полный FOV, MJPG,
  программное уменьшение). Подробности и замеры — в `README_CAMERA.md`.
- `rpi_ks.py`: старый сервис на Picamera2, с текущей USB-камерой не работает.
- `uart_rpi.ino`: файл приема данных с Raspberry pi на Arduino.
