# UniKostyl

Расширенная версия проекта [OpenKostyl](https://github.com/WildBoar228/OpenKostyl).
Предоставляет интерфейс для цветовой калибровки камеры, т.е. подбора цветового диапазона в формате LAB для некоторых объектов интереса.

### Для запуска :

- открыть файл `cv_kostyl.py`: принимает в качестве аргумента кадр с камеры, обеспечивает работу
  с пользовательским интерфейсом.
  `работа приложения`
  Вводиться IP адрес одноплатника => Выделение и калибровка цветового диапозона => Отправка цветового диапазона (кнопка `save`) в формате RGB обратно на одноплатник

## Управляющие файлы

- `cv_kostyl.py`: использует веб-камеру устройства.
- `rpi_ks.py`: главный файл на Raspberry pi.
- `uart_rpi.ino`: файл приема данных с Raspberry pi на Arduino.
